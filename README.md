# Project Factio

Project Factio is a first-person survival horror game currently in development using Unreal Engine 5, C++, and Blueprints.

The project focuses on stealth, exploration, environmental interaction, and enemy avoidance rather than combat.

## My Role

Solo Developer

I am responsible for:

- Gameplay programming
- AI behavior
- Interaction systems
- Level design
- Puzzle and encounter design
- Inventory and item systems
- Testing and debugging

## Current Systems

- First-person movement
- Enhanced Input
- Sprinting and crouching
- Interaction system
- Key and locked-door system
- Inventory support for puzzle items
- Enemy sight and hearing perception
- Chase behavior
- Patrol behavior
- Last-known-position investigation
- Search behavior after losing sight of the player
- Environmental noise distractions
- Checkpoint and respawn system
- Prototype horror environments

## Development Tools

- Unreal Engine 5
- C++
- Blueprints
- Visual Studio
- Git / GitHub
